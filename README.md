# 🌍 Travel With Us

**Travel With Us** is a modern, fully responsive travel booking website that helps users explore dream destinations, book vacation packages, and plan their perfect getaway. Built with clean UI/UX principles, this project showcases a complete travel agency website with booking functionality, destination galleries, package deals, and customer testimonials.

🔗 **Live Demo:** [travel-with-us-online-booking.netlify.app](https://travel-with-us-online-booking.netlify.app)

---

## ✨ Features

### 🏖️ **Core Functionality**
- **Popular Destinations** - Browse iconic locations like The Colosseum, Burj Khalifa, Tokyo Temple, Niagara Falls, and more
- **Exclusive Travel Packages** - Hand-crafted vacation packages with pricing (East African Safari, Santorini Greece, etc.)
- **Smart Search Widget** - Search by location, dates, and number of guests
- **Booking System** - Direct booking links with package details and pricing
- **Customer Reviews** - Real testimonials from travelers
- **Newsletter Subscription** - Stay updated with latest deals and travel tips

### 🎨 **Design & UI**
- **Responsive Design** - Works seamlessly on mobile, tablet, and desktop devices
- **Modern UI/UX** - Clean layout with intuitive navigation
- **Interactive Elements** - Smooth animations and hover effects
- **Mobile Menu** - Hamburger navigation for mobile users
- **Card-based Layout** - Organized destination and package cards

### 📦 **Additional Features**
- Login/Authentication page
- Contact form with location details
- 24/7 Support information
- Best Price Guarantee section
- Expert Local Guides showcase
- Easy booking process

## 🚀 How to Run Locally

### 1️⃣ Clone the Repository
```bash
git clone https://github.com/DeepakDubat/travel-with-us.git
cd travel-with-us
```

### 2️⃣ Open in Browser
Simply open `index.html` in your preferred web browser:
```bash
# On Windows
start index.html

# On macOS
open index.html

# On Linux
xdg-open index.html
```

### 3️⃣ Navigate the Website
- Explore destinations and packages
- Try the booking flow
- Fill out the contact form
- Subscribe to newsletter
